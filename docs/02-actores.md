# Actores
A continuación se documentarán los actores del sistema
## Operario en bodega
* Acciones permitidas:
  * Consultar el "pool" de ordenes tanto de ingreso como de despacho.
  * Seleccionar ordenes o grupo de ordenes para su gestión.
* Acciones restringidas
  * Cambiar estados a las ordenes o movimientos del sistema.
* Errores posibles:
  * Error de digitación en las cantidades.
